nome

Switch between Linux distros and their user data. One static binary. No root, no containers.

git clone --depth 1 https://github.com/mkalmousli/nome && cd nome && ./build.c install

Try it

# download Ubuntu into a profile called "mo"
$ nome get ubuntu mo
ready: nome mo

# bash by default, any command on request
$ nome mo
root@host:/# id -u
0
$ nome mo ls /
# or just run nome for the guided TUI
$ nome

Why nome

  • Standalone - emuroot is compiled in; one static binary.
  • Rootless - fake root through ptrace; apt, apk, pacman and dnf work as an ordinary user.
  • Your data stays yours - each profile has a private /root that survives reinstalling the distro.
  • Pure C - no build system beyond build.c: run it directly, it builds, installs (with man page) and uninstalls.
